# Midnight Hackathon 2026 — Scope

## Existing MissionVault-Sentinel foundation

The existing application provides:

- Satellite telemetry ingestion
- Deterministic anomaly detection
- Incident creation
- Incident reconstruction
- AI-assisted investigation
- Human operator decision workflow
- Evidence package generation
- SHA-256 integrity verification
- React dashboard

## Hackathon objective

Extend the mission evidence workflow with a real Midnight privacy and
verification layer.

## New implementation scope

The hackathon work focuses on:

1. Compact smart contract
2. Private mission evidence representation
3. Midnight proof/transaction workflow
4. Backend-to-Midnight integration
5. Verification flow
6. Frontend privacy status
7. Tamper/integrity demonstration

## Target workflow

Telemetry
→ Incident
→ AI Investigation
→ Human Decision
→ Evidence Package
→ Midnight Privacy / Verification
→ Verifiable Result

## Principle

Sensitive mission information should remain private while the system
produces a verifiable result that can be checked without exposing the
underlying evidence.

## Non-goals

- Autonomous spacecraft control
- Complex machine learning training
- Native mobile application
- Cross-chain integration
- Physical spacecraft hardware
- Large multi-contract architecture
